# Journal Site

A journal web-app made with HTML/CSS/JS and a Flask API using SQLite, served through Flask.

## What I Learned
- How to make a (Rest) APIs with Flask
- How to interact with SQLite in Python
- Handling CORS
- Managing and using relational databases

## How to Run
1. Clone the repository
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Run:
   ```bash
   python main.py
   ```
5. CTRL + click the link in the terminal
6. Now you can use the website!
